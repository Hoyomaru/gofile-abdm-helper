# GoFile ABDM Helper v1.2.1

2026-09-27

新機能を追加せず、既存の送信処理・GoFile resolve・テスト・運用再現性を改善したbug-fix releaseです。

## Fixed

- ABDM接続確認中に送信操作を連続した場合、同じ選択の登録処理が複数開始し得る競合を修正
- send operationを最初の非同期preflightより前に予約し、接続確認中も二重操作を排他
- preflight中のnavigation / manual Load / Cancel Sendでもgeneration guardを維持
- 極端に深い・大きいGoFile treeを明示的な安全上限で停止
  - nested folder depth: 128
  - resolved node count: 100,000
  - 超過時: `422 tree_limit_exceeded`
- treeの公開用serializationとsize / file count集計を反復処理化し、再帰上限への依存と重複集計を削減

## Operations / Diagnostics

- fresh resolveが10,000 node以上、または30秒以上の場合だけaggregate warningを記録
- diagnostic logはfiles / nodes / max depth / durationのみ
- URL、content ID、token、Cookie、password、direct URL、save pathは記録しません
- release smoke checklistを現行send UIと二重操作確認へ同期
- release gateで実際に解決したPython依存を `python-dependencies-v1.2.1.txt` としてRelease assetへ添付
