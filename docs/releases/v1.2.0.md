# GoFile ABDM Helper v1.2.0

2026-09-27

送信操作とWindows導入・トラブル切り分けを簡潔にするbackward-compatible feature releaseです。

## 主な変更

- GoFile toolbarを **ABDMへ送信** 1つのprimary actionへ整理
- **フォルダ構造を維持** checkboxでstructure / flatを切り替え
- DOM matchingが必要な場合だけ **一覧から選択** を表示
- `setup-windows.cmd` でlocal `.venv`作成→依存導入→検証→tray起動
- Settingsへ **自己診断** を追加
- Helper / ABDM offlineを分離して表示し、Queue件数も確認可能
- `start-tray.cmd` はlocal venvを優先

## Security / Safety

- diagnosticsはread-only ABDM `GET /queues` のみ
- credential / password / GoFile token / direct URL / save pathを診断レスポンスへ含めません
- localhost-only Helper、request marker、uncertain POSTのblind retry禁止を維持

- Python regression suite + py_compile: PASS

- Windows one-step setup smoke + idempotent reuse: PASS
- 2026-09-27 実機: setup / tray / Helper↔ABDM自己診断 / 送信UI PASS
